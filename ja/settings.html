NoKiridding

基本の機能：偽文字を見つける

接続先のドメイン名に、キリル文字や英字にそっくりな別の文字がないかを調べます。対象の文字を見つけると接続を止め、警告画面でその文字と理由を示します。

下の例は、先頭の英字「a」を、見た目がそっくりなキリル文字「а」に置き換えています。赤く示した文字は英字ではないため、接続を止めて警告します。

本物のドメイン
amazon.com
遮断する文字の例
аmazon.com

この基本の検査は、サイトをリストに登録しなくても働きます。対象は、サブドメインから末尾の .com などまでのドメイン名です。URLのパスや検索条件は調べません。

オプション機能

上記の基本機能に加えて、文字の組み合わせで騙してくるパターンにも対応する機能です。対象が無限にあるため、フィッシング詐欺に狙われやすい100社を登録してあります。追加したい場合は、以下から追加してください。

フィッシング詐欺に使われやすいドメイン

ここには、なりすましを見つけたい会社やサービスの本物のドメインを登録します。登録済みの141ドメインは、設定しなくても自動で確認します。

例えば、次のような置き換えを調べます。以下は文字の見間違いを説明するための作例です。登録した本物のドメインに似ている接続先を見つけると警告します。

  • rn / m：amazon → arnazon。「r」と「n」を並べて「m」に見せます。
  • 0 / o：google → g00gle。英字の「o」を数字の「0」に置き換えます。
  • 1 / l / i（I）：paypal → paypa1。小文字の「l」に数字の「1」や大文字の「I」を似せます。小文字の「i」も比較の対象です。
  • vv / w：windows → vvindovvs。「v」を2つ並べて「w」に見せます。
  • cl / d：adobe → aclobe。「c」と「l」を並べて「d」に見せます。

大文字の「I」について：Chromeはドメイン名を小文字にそろえるため、入力された「I」は「i」として、数字の「1」や小文字の「l」と比較します。見え方はフォントによって異なります。

例：amazon.com。公式サイトで確認した本物のドメインを、半角英数字で入力してください。偽サイトのドメインは登録しません。複数ある場合は改行かカンマで区切ります。https://・URLのパス・「*」は入力しません。

登録済みのドメイン

普段使う会社やサービスも、上の入力欄から追加できます。登録済みの項目は、下の一覧で編集・削除できます。警告を省略して接続を許可する場合は、別の「許可リスト」を使います。

読み込んでいます。

該当する登録はありません。

    警告せずに開く（許可リスト）

    警告を省略する接続先です。警告画面で「この接続先を今後も許可する」にチェックして続行すると保存されます。許可中は、基本の偽文字検査と追加の類似判定の両方を省略します。削除すると次に開くときから再び検査します。タブ内だけの一時許可は、この一覧には表示しません。

      保存される場所

      許可リストと、追加・編集したドメイン一覧は、この端末のChromeプロフィール内に保存されます。外部への送信や、ほかの端末への同期はしません。

      削除すると、同じ接続先のタブ内だけの許可も解除します。すでに開いているページを閉じる操作ではありません。
